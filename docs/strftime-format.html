Calendar custom date and time formats

Calendar uses the platform strftime-style date and time syntax. This reference is installed with Calendar so format help remains available offline.

TokenMeaning
%Yfour-digit year
%ytwo-digit year
%mmonth number
%Bfull month name
%babbreviated month name
%dday of month, zero padded
%-eday of month without leading padding
%Afull weekday name
%aabbreviated weekday name
%Hhour, 24-hour clock
%-lhour, 12-hour clock without leading padding
%Mminute
%Ssecond
%plocale AM/PM marker
%R24-hour hour and minute
%nline break
%%literal percent sign

Names, ordering and AM/PM text follow the active locale. Custom text is displayed as entered; Calendar does not force capitalisation.
